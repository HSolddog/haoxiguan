## 总体判断

这是一个具备完整界面和基本习惯闭环的 Flutter 原型。值得保留 Flutter、温和风格、分类、备注、日历和记录经验；需要重建核心存储、计划历史、文件恢复与提醒调度。没有证据说明必须换框架，当前的主要问题是整体 JSON 状态和当前规则回算全部历史。

## 重构决策

保留 Flutter 是因为当前跨平台需求与共享界面适配它、已有实现可渐进利用，而非盲目沿用。替换整体 JSON 存储、静默历史回算、剪贴板主备份方式。用户真实记录、主题、备注、分类和旧奖励信息必须保留。优先级：单机数据可靠 → 正确记录与回顾 → 自选备份 → 同步 → 体验扩展。
