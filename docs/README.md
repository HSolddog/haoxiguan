# 好习惯：产品与工程文档

> 2026-10-03。Android 开发版 1.2.0+6；逻辑格式 7、SQLite schema 3。本文区分设计规格、当前实现和验证证据。

好习惯是 MIT 开源、离线优先、数据可自行保存的个人习惯工具。不注册、不设置备份、不连接同步服务，也应完整保存和使用本机记录。官方托管与自行部署使用相同的开源软件和协议；iOS 后续共享领域模型、格式与主要界面，本轮不制作。

用户已确认首轮完成型、计数型和手动时长；加密覆盖独立备份与小型自建同步；普通使用和兼容覆盖升级的数据完整性不依赖用户额外启用云功能。
