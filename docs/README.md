## 已确定的方向

**完全开源、离线可用、数据由用户掌握的个人习惯工具。Android 当前优先制作和验收；iOS 未来共享业务模型、数据协议和主要界面。**

用户已确认：继续 MIT；第一轮实现完成型、计数型、手动时长，专注计时后置；加密要覆盖自建小型同步服务；即使不接入同步和用户备份，正常使用和兼容覆盖升级也必须保持本地数据完整。

本地可靠性是基础能力，不需要注册、订阅、服务器、网盘或用户先做备份。同步和备份是可选增量。官方早期托管与自部署使用同一开源软件和协议，不能以闭源模块限制自行部署或导出。

## 分阶段交付

| 阶段 | 交付 |
| --- | --- |
| A | Android 可靠单机版：三类记录、正确统计、本地保护、升级迁移、提醒、文件导出恢复 |
| B | 用户自选加密备份：WebDAV、自动尝试、保留、失败诊断和恢复 |
| C | 可选端到端加密同步：小型自部署、设备管理、冲突、官方同协议托管 |
| D | 根据使用反馈选择 Widget、专注计时和正向奖励 |
| iOS | 独立后续制作与验收，不绑定 A/B/C 的交付时间 |

客户端推荐 Flutter + SQLite/Drift；同步服务首版推荐单实例 Go + SQLite，支持 ARM64/x86_64 Linux、原生二进制或单容器。PostgreSQL 是实测有扩容需求后的选项，不作为个人部署的前置条件。
