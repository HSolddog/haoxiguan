## 已实现的产品

| 范围 | 行为 |
| --- | --- |
| 本地记录 | 无账号、无网络、无云配置可完整使用；完成、精确计数、手动时长；当天明细、单条撤销、备注、补记与更正 |
| 计划与回顾 | 每天、指定星期、每周 N 天、每月 N 天；计划历史和未来生效；休息、暂停、归档、回收站；旧奖励只读保留 |
| 本机可靠性 | SQLite WAL/FULL 事务、版本 CAS、提交后确认；旧数据兼容迁移、恢复前保护；损坏及未知未来版本停止写入，保留原数据 |
| 文件与外观 | Argon2id/XChaCha20-Poly1305 加密文件；恢复预览；明文 JSON/CSV；系统、浅色和深色主题；隐私与第三方许可入口 |
| 自选备份 | HTTPS WebDAV；不可变加密快照、读回校验、保留清理；后台和前台尝试；未开启时不序列化整份历史，开启时只读取已提交数据 |
| 自建同步 | Go/SQLite；端到端加密；设备邀请、加密恢复材料、手动同步、冲突差异确认、撤销设备、恢复后重新核对、维护式密钥轮换 |
| 服务运维 | Linux amd64/arm64 二进制；单容器、非 root、TLS 模板、一致备份、恢复后新 epoch；分发包附原始许可证文本 |
| 提醒 | 本地非精确通知、显式行为日期、通知动作、稍后提醒、滚动安排、WorkManager 与前台续排 |

本地 SQLite 依靠系统沙箱和设备加密；没有宣称已实现独立数据库口令锁。文件备份和同步内容另有应用层加密。服务器仍能看到账户、设备、对象大小和访问时间等元数据，详见[隐私说明](隐私与数据说明.md)。

## 已验证

- Flutter 格式、静态分析及 100 项普通自动化通过；需要真实服务的 2 个集成套件默认跳过，另以明确环境显式执行。
- Go 14 项普通回归、race/vet 和 Linux 双架构静态构建通过；包括冻结 schema 1→2 的重复迁移和中途 DDL 失败回滚。
- 真实 HTTPS 双客户端的加密互通、离线合并、冲突、设备撤销、恢复材料换机、服务恢复和维护式密钥轮换通过。
- WsgiDAV、Nextcloud 两套实际 HTTPS 服务的加密备份、读回和恢复集成通过。
- 同一批原生夹具在 API 24/35/36 完成无云写入、Keystore、加密文件往返、强停重开、同签名 APK 覆盖及实际 schema 2→3，并通过系统文件保存/读回/选择/超限拒绝、真实后台入口和周期任务注册。API 35/36 证据来自 [CI 36999580510](https://github.com/HSolddog/haoxiguan/actions/runs/36999580510)；API 24 在确认应用源码未变后复用同一批已编译 APK，由 [CI 37001861441](https://github.com/HSolddog/haoxiguan/actions/runs/37001861441) 通过。前一运行中的 API 24 失败保留在记录中，不将整个旧运行标记为全绿。
- 1 CPU/1 GiB 容器的持久重启、一致备份和恢复后撤销旧令牌通过；20 用户/60 设备/十万对象的存储、引导与备份容量诊断通过，不包含 HTTP/TLS/网络成本。

原始 JSON 报告、运行地址、产物摘要、失败原因及未执行项目见[验收记录](验收记录/2026-10-02.md)。旧过程记录归档于 [history](history/2026-10/实施增量记录.md)。

## 性能边界

十万事实记录的主机 JIT 保存诊断由约 28 秒降至 76–113 ms：不可变对象回滚、变更习惯局部事务、全局 ID 归属校验，提交和回滚保证不变。大库重开仍约 7 秒。两者均不是 Android AOT/真机 P95；不能据此宣称达到正式性能目标。测试规模、次数和原始报告见[性能诊断](性能诊断.md)。

## 正式交付前的剩余项目

1. 原始发行证书、真实旧版本和脱敏旧数据样本核对。release 缺签名即失败，不会自动换用临时 debug 签名，也不要求旧用户卸载重装。
2. 真机 TalkBack、低端机与大库性能、锁屏/重启/省电/厂商 ROM 通知动作、连续试用。一次性后台入口执行与周期任务注册只证明对应代码可运行，不证明系统会按 12 小时周期或厂商会准时调度。
3. 同步的完整 Android 界面联网流程、端到端规模和故障压力、ARM64 服务实际运行及独立密码学审阅。当前同步保留实验性标识。
4. 官方服务域名、主机、备份保存期、费用和运营规则。当前没有公开生产部署；自建软件与托管软件同一代码，不设专有模块。

Widget、完整专注计时、奖励重设计和 iOS 按范围后置。正式验收不会以 Debug 构建、模拟器或合成样本替代尚未取得的实物证据。
