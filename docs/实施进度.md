## 最近完成的检查

`71529c3abc5fca00635a50cb17e9bb78055dc40e` 的 [Android CI 36988029384](https://github.com/HSolddog/haoxiguan/actions/runs/36988029384) 与 [Go CI 36988029414](https://github.com/HSolddog/haoxiguan/actions/runs/36988029414) 全部通过。包含格式、静态分析、应用回归、真实 HTTPS 密钥轮换、Debug APK、API 24/35/36 原生升级、Go race/vet/双架构编译和容器恢复。

`5f1cd06ec3a3d50c999632bf07768c8966d3e5d4` 增加 CSV、系统主题和有界 Android 文件读取。原插件会过滤未注册扩展名，且按提供方 SIZE 元数据分配整份内存。现在通过 ACTION_OPEN_DOCUMENT 接收文件，原生侧 64 KiB 缓冲流式复制，超过 50 MiB 停止并删除临时文件；Dart 再验证格式和密码。新增系统窗口写入/读回/选取/解密及 51 MiB 拒绝用例，[CI 36989686873](https://github.com/HSolddog/haoxiguan/actions/runs/36989686873) 的 API 35 全流程通过。API 36 的合成文件写入早于共享存储就绪，API 24 的 Downloads 提供方不展示 adb 直接创建文件；验收夹具改为先通过 SAF 建立条目再扩展文件，同时覆盖提供方 SIZE 元数据过时的场景。两者仍待重跑，不计应用验证通过。

原始报告、历史运行和摘要见[验收记录](验收记录/2026-10-02.md)；旧增量叙述归档在 [history](history/2026-10/实施增量记录.md)，避免把历史“未实施”误读为当前状态。

## 大数据量保存修复

本地全套 98 项通过，十万条记录的云端 JIT 保存诊断从约 28 秒降至 76–113 ms。采用不可变对象回滚、变更习惯的局部事务和全局 ID 归属检查，避免反复解析所有历史；未降低提交确认、CAS 或回滚保证。大库重开仍需优化，数值不代替 Android 真机性能验收，详见[性能诊断](性能诊断.md)。
