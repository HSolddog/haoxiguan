# 加密备份格式 v1

本页描述已实现的文件格式，代码见 `lib/services/backup_codec.dart`。备份加密和本地数据库是独立能力：当前 SQLite 使用 Android 私有目录和系统设备存储保护，没有宣称 SQLCipher 或应用级数据库加密。纯离线使用不依赖此功能。

## 密码与算法

- 容器是 UTF-8 JSON，后缀 `.hgb`。密码按 UTF-8 原样编码，不 trim、不做 Unicode 规范化。创建至少 12 个 Unicode 标量，最多 1024 个 UTF-8 字节；恢复不会以最小长度规则拒绝旧密码。
- 使用 libsodium 的 Argon2id v1.3，内存 65536 KiB、迭代 3、并行度 1，输出 32 字节。每个文件独立生成随机 16 字节盐。
- 使用 XChaCha20-Poly1305 IETF，随机 24 字节 nonce，密文末尾包括 16 字节认证标签。密码派生和文件加解密在独立 isolate 执行。
- 严格限制输入参数后才执行 KDF；当前仅接受这一组参数，不使用文件提供的任意内存和迭代值。
- 密钥通过 `SecureKey.dispose()` 释放，可变密码和明文缓冲区在 finally 中尽力清零。Dart 不可变 String 与运行时副本不能承诺全部清零；不将密码写入备份或日志。

## 外层字段及认证编码

外层恰有 `format`、`formatVersion`、`appVersion`、`encrypted`、`crypto`、`payload`、`payloadSha256` 七个字段。

- `format = "haoxiguan-backup"`，`formatVersion = 1`（整数），`encrypted = true`。
- `crypto` 恰有 `suite = "argon2id-xchacha20poly1305-v1"`、`salt`、`kdfParams`、`nonce` 四个字段。
- `kdfParams` 恰有 `memoryKiB = 65536`、`iterations = 3`、`parallelism = 1` 三个整数字段。
- 二进制采用带标准 padding 的 RFC 4648 Base64，拒绝非规范编码。
- `payload` 是密文与标签；`payloadSha256` 是它们的 SHA-256 小写十六进制。摘要只用于传输损坏检查，真实性由 AEAD 保证。

AEAD additional data 是下面数组的紧凑 JSON 的 UTF-8 字节，严格按顺序编码，无空格或换行。不能使用对象的任意字段遍历顺序代替：

```text
[format,formatVersion,appVersion,encrypted,crypto.suite,crypto.salt,
 crypto.kdfParams.memoryKiB,crypto.kdfParams.iterations,
 crypto.kdfParams.parallelism,crypto.nonce]
```

外层 JSON 的排版不影响认证；更改被认证字段会导致失败。

## 解密内容

内层为 `{ "manifest": {...}, "data": {...} }`。`manifest` 包含随机 `snapshotId`、UTC `createdAtUtc`、`sourceVaultId`、`dataSchemaVersion`、`habitCount`；`data` 是完整的逻辑数据快照。读取时验证数据格式、版本、计划和记录约束，并校对清单版本及习惯数。凭据、设备私钥和服务器配置不属于业务快照。

恢复需要文件选择、密码、完整校验、数量预览及替换确认，最后在数据库事务中保护原快照并替换。恢复创建新的本地空间 ID，保留原空间来源，不自动连接原服务器。

## 大小与文件行为

当前文件上限 50 MiB，内层明文上限 36 MiB，给 Base64 和头部留出空间。超限明确失败，不删除本机内容。导出前解密校验一遍；Android 通过系统文件选择器写入后再次读取并比对完整文件摘要，只有成功读回才提示成功。这不等价于第三方云盘已完成远端上传。

明文 JSON 导出是独立、明确告知的选项。用户选择密码丢失时，维护者和服务器无法解密文件。

## 验证证据与限制

`test/fixtures/backup-v1-vector.json` 是使用 Python ctypes 直接调用 libsodium 生成的合成公开向量，包括密码、派生密钥、AAD 与容器，仅用于测试，不包含用户数据。测试覆盖该向量、随机盐/nonce、往返、错误密码、密文修改后重算摘要、头部修改、截断、未知算法和恶意 KDF 参数。

2026-10-02 已通过 Linux 原生 libsodium 测试；Android 原生库装载、系统文件选择器、16 KiB 页面对齐与真实设备性能仍需独立验收。算法选择和测试通过不能代替独立密码学审查。iOS 文件导出适配暂未发布。
