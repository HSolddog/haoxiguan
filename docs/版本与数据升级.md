# 版本与数据升级

## 导出 APK

统一从项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_release_apk.ps1
```

脚本只在 APK 构建成功后更新 `pubspec.yaml`。每次成功导出都会同时递增：

- 可见版本的补丁号，例如 `1.0.0` → `1.0.1`
- Android `versionCode`，例如 `1` → `2`

产物会保存为 `dist\haoxiguan-v1.0.1+2.apk`，因此不会混淆不同版本。

## 保留用户数据

- 应用状态继续使用固定键 `haoxiguan.app_state.v1`，版本升级时不更换键。
- 写入新状态前会保存上一份完整状态；主状态异常时自动使用备份恢复。
- 新字段必须在 `Habit.fromJson` 和控制器恢复逻辑中提供兼容默认值，不能通过清空旧状态完成升级。
- Android 包名必须保持 `com.haoxiguan.haoxiguan`，升级包必须使用与旧包相同的签名。
- 发布脚本会优先复用本机最近使用的 Android 更新证书；更换电脑前必须安全迁移原证书。
- 安装新 APK 时直接覆盖安装，不要先卸载应用，也不要清除应用数据。

发布前应运行：

```sh
flutter test
flutter analyze
```
