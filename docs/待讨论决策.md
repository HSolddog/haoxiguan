## 技术和产品默认值

- Flutter + SQLite/Drift、领域与平台分离。
- 同步首版 Go + SQLite 单实例，原生二进制／单容器，官方早期同版；PostgreSQL 按实测扩容后演进。
- 今日／习惯／回顾／设置；数据中心区分本机保存、备份和同步。
- 自然日 00:00 切日，周一起算；计划未来生效，历史版本保留。
- 备份先文件再 WebDAV，同步后做；WebDAV 不自动合并多设备。
- 回收站 30 天；恢复先保护原数据；首版无附件和服务器联邦。
- 新用户弱化奖惩，旧奖励配置和余额只读保留，不悄悄清掉。

这些是可逆设计选择，不需要为每一个默认值再次停下来求确认；新证据出现时更新规格和验收。
