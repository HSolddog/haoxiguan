# Android 开发版试用

本次交付是 1.1.0+5 开发版，不是正式发行。源码、运行记录及构建下载见[实施进度](实施进度.md)和[验收记录](验收记录/2026-10-02.md)。先用专门的测试设备或独立测试用户配置；以下只录入可丢弃的合成数据。

## 安装与更新

普通 APK 包名仍为 `com.haoxiguan.haoxiguan`。CI Debug 证书不代表已有安装的原始签名，也不能保证不同 CI 作业的 Debug 包彼此兼容。

- 没有旧数据的测试配置可安装开发包。
- 已有安装若出现签名不匹配，停止安装并保留旧应用。不要卸载、清除存储或删除数据库来绕过。
- 正常更新验收必须取得原始证书对应的签名方式，先在旧版本建立数据，再覆盖安装新版本，逐字段核对。CI 使用独立包名的两份同签名夹具，只证明该测试链路。

## 优先试用的六条路径

| 步骤 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 1. 无云开始 | 打开飞行模式；首次打开，不配置账号、备份或同步 | 空白开始，可直接创建习惯，无示例历史 |
| 2. 三种记录 | 建立每日完成型、计数型和手动时长型；分两次记录，添加中文备注 | 数值准确累计；备注独立保留；明细中可只撤销其中一次 |
| 3. 本机重开 | 等待记录确认后，系统强制停止应用，再打开 | 习惯、明细、备注、计划和主题保持；仍无需云功能 |
| 4. 历史与计划 | 补记昨天；调整下一周期目标；暂停、恢复、归档并查看历史 | 不允许未来记录；旧计划和旧事实保留；归档不删除历史 |
| 5. 加密文件恢复 | 导出加密文件；再修改本机内容；选择该文件，先试错密码，再用正确密码预览并确认恢复 | 错密码不改变本机数据；正确恢复前先保护原数据；新空间不自动继续向旧同步空间写入 |
| 6. 回收与可读导出 | 删除习惯再从回收站恢复；查看 JSON/CSV 导出及明文提示 | 原记录和备注完整恢复；可读导出明确为明文，不把 CSV 当完整恢复备份 |

文件窗口可选择用户自己的存储提供方。安卓 7 系统列表可使用“长按选中 → 打开”；取消窗口应回到应用，不修改数据。超过限制、截断或篡改的文件应安全拒绝。

## 提醒和自选服务

通知先检查系统权限，记录设置的时间和实际出现时间；分别试锁屏、回到前台、重启和省电模式。强制停止后系统可能暂停通知和后台任务，重新打开后应补排。自动化的一次性后台任务验证不代替这些真机行为，也不承诺精确到点。

需要试 WebDAV 时，使用专门的测试目录和可撤销的应用密码，按[WebDAV 配置与验收](WebDAV配置与验收.md)执行写入、读回、列表和换机恢复。自动备份受系统调度、网络策略和每日频率控制，“已配置”不等于“已备份成功”。

自建同步仍为实验性功能。用两个隔离测试设备和合成账号，按[同步实现与验收](同步实现与验收.md)验证两端离线新增、同一内容冲突、设备撤销和断开后的本地保留。恢复文件只含解密材料，不含完整历史；完整加密备份仍需独立保管。

## 反馈记录

记录 APK 版本和源码提交、手机型号、Android/ROM 版本、步骤、预期、实际结果以及是否可重复。数据问题要区分“界面已确认保存”“尚在保存”“升级”“卸载或清除存储”。

不要在公开 issue 中粘贴数据库、真实习惯、存储密码、令牌、密钥、加密恢复文件或签名私钥。若发现数据不一致，保留当前安装和文件，停止继续修改；不以重装证明问题消失。
